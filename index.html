Which Decision Method Should You Use?

Choose a method based on the structure of your problem, the data you have, and the type of result you need. These short descriptions help you select a suitable starting point before opening a calculator.

AHP: derive criteria weights

Use the Analytic Hierarchy Process when you need to structure a goal into criteria and sub-criteria, compare them in pairs, and assess judgment consistency. Try AHP Decision Engine v2.

TOPSIS: rank alternatives

Use TOPSIS when alternatives are evaluated across multiple criteria and you want to rank them by relative closeness to an ideal solution. Try TOPSIS Decision Engine v2.

SAW: calculate weighted scores

Use Simple Additive Weighting when normalized criterion scores can be combined into a weighted sum, with explicit handling of benefit and cost criteria. Try SAW Calculator Engine v2.

Decision Trees: analyze sequential choices

Use decision trees when choices lead to uncertain outcomes or later decisions. Expected Monetary Value (EMV), rollback, and value-of-information analysis can help compare strategies under stated assumptions. Try Decision Tree Calculator v2.

Bayesian Networks: update probabilities

Use Bayesian analysis when a problem involves uncertain variables and evidence that changes the probabilities of possible outcomes. Results depend on the network structure, conditional probabilities, and evidence entered. Try Bayesian Calculator Engine v2.
