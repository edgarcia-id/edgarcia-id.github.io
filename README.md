This repository hosts the front-end landing page that connects a curated ecosystem of tools designed to help IT Leaders, CIOs, and Business Owners manage risk, calculate ROI, and automate compliance reporting.

## 🛠️ The Architecture (Privacy by Design)
As an IT Governance & Compliance consultant, I prioritize data privacy above all else. 

All calculators, generators, and simulation tools linked in this portfolio are engineered to run **100% client-side** using Vanilla JavaScript. 
* **Zero Data Collection:** No databases, no external API calls (unless explicitly simulated), and no tracking cookies.
* **Audit-Ready:** Outputs (such as RFCs, Timesheets, and Post-Mortems) are generated directly within the user's browser as secure PDFs.
